# Hardware — FLORA

Abre `FLORA.kicad_pro` con **KiCad 10** (los archivos `.kicad_sch` y `.kicad_pcb` están en formato KiCad 7 y se actualizan al guardar). Contenido: esquemático, placa rutada, símbolo del módulo ESP32-C3-WROOM-02 (`FLORA.kicad_sym` + `sym-lib-table`), `bom.csv`, `pinout.csv`, `gerbers/`, `drill/`, `assembly/FLORA_pos.csv`.

Primer paso recomendado: ERC (esquemático) y DRC (PCB) en KiCad.
