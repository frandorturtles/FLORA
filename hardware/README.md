# Hardware — FLORA

Abre `FLORA.kicad_pro` con **KiCad 10**. Contenido: `FLORA.kicad_sch` (esquemático), `FLORA.kicad_pcb` (placa rutada), `FLORA.kicad_sym` + `sym-lib-table` (símbolo del módulo ESP32-C3-WROOM-02), `bom.csv`, `pinout.csv`, `gerbers/`, `drill/`, `assembly/FLORA_pos.csv`.

Primer paso recomendado: ERC (esquemático) y DRC (PCB) en KiCad, y volver a trazar los Gerbers (ver `../manufacturing/gerber_checklist.md`).
